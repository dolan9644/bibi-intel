Agent 不再拼嘴炮，开始拼自测、风控和上下文成本

核心阵地

一、Codex 的真壁垒不是会写代码，而是会把自己拉到浏览器里挨打

Peter Yang 对 Codex 的判断像一把刀：真正的 agentic coding 不是把代码吐出来，而是写完以后敢打开浏览器、跑页面、读控制台、截图验收，再把自己生成的垃圾回炉。过去两年 AI 编程从补全、聊天改代码，走到今天的执行闭环。浏览器自测不是锦上添花，它是把模型从作文机拖进工程现场的验尸台。

这意味着 AI coding 工具的竞争重心正在从“谁更会写”切到“谁更会验证”。设计和前端审美任务上 Claude 仍有优势，Codex 的价值则长在执行与自测链路上。未来团队会像交易员配资产一样配模型：重构、测试、后端修复交给能自测的代理；复杂视觉、品牌页面、交互表达交给更会审美推理的模型。

Dolan's 锐评：没有浏览器验收的代码 agent，本质还是老虎机，偶尔吐金币，大多数时候吐技术债。能自测，才有资格进生产。

来源：Peter Yang、Garry Tan

二、OpenClaw 的两条信号：依赖瘦身和 token 预算，正在把 agent 从玩具逼成工程品

Peter Steinberger 给出的 OpenClaw 信号很硬：移除 Sharp 与 Jimp，改用 Rust/WASM photon，图像处理依赖从约 140MB 降到 2MB；同时开始把 skill token 浪费当工程问题治理。一个是二进制体积，一个是上下文成本，底层都是同一件事：agent 工具开始进入运行时经济学。

桌面 agent、IDE agent、本地自动化壳子，不能永远靠 demo 光环活着。包体大小、安装失败率、冷启动速度、供应链攻击面、上下文常驻成本，都会变成留存和毛利的硬约束。skill 文件不是许愿池，每个字都会在推理时扣钱，也会稀释注意力。

Dolan's 锐评：上下文不是免费自助餐，是运行时内存。把 skill 写成大部头的人，本质是在用平台毛利给自己的表达欲买单。

来源：Peter Steinberger、Ryan Carson 方法论转述

终局研判

今天的牌面很冷：AI 行业正在从“模型智商竞赛”掉进“工程会计审判”。会写代码不够，要能自测；会组织 agent 不够，要算 token；会卖自动化不够，要回答劳动尊严；会做预测市场不够，要拿牌照；会抽 Wikipedia 不够，要解释谁养知识公地。下一轮赢家不是最会喊 AGI 的公司，而是能把执行、验证、成本、权限、身份和合规压进同一套冷冰冰机器的人。
